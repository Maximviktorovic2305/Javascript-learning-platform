# Как выполняется JavaScript
## Язык, движок и среда выполнения
JavaScript — язык, на котором записывают действия программы. Движок читает этот текст, проверяет его структуру и выполняет инструкции. Среда выполнения добавляет готовые возможности. Браузер умеет показывать страницу, а Node.js запускает JavaScript без страницы. Например, имя document обозначает браузерный объект документа: это возможность браузера, а не обязательная часть самого языка. На сервере такого документа обычно нет.

В этом уроке достаточно понять последовательное выполнение, вызов готовой команды и возврат значения из предоставленной функции. Условия, циклы, массивы, обработчики событий и работа с HTML пока не нужны. Их нельзя угадывать по незнакомому примеру: у каждого механизма будет своё объяснение. Теория и практика ниже используют строки, имена и простую оболочку функции. Строка — текст в кавычках; имя позволяет обратиться к уже переданному значению.

## Первая программа и порядок инструкций
Откройте консоль инструментов разработчика браузера. Готовая команда console.log показывает переданные значения. Точка соединяет имя console с названием его команды log. Круглые скобки означают вызов команды, кавычки выделяют текст, а запятая разделяет несколько значений. Завершающая точка с запятой отделяет инструкцию. Команды выполняются сверху вниз, поэтому порядок строк влияет на порядок сообщений.

```javascript
console.log('Первая инструкция');
console.log('Вторая инструкция');
console.log('JavaScript', 'работает');
```

```output
Первая инструкция
Вторая инструкция
JavaScript работает
```

В файле hello.js работают те же инструкции. Node.js может выполнить такой файл командой node hello.js. Терминал и консоль браузера — разные места запуска, но эти простые команды не обращаются к странице и подходят обеим средам. Пока не нужно устанавливать библиотеки, подключать модули или создавать сервер.

## Готовая функция solve: имя, параметр и тело
Практика платформы предоставляет оболочку function solve(message) с фигурными скобками. Слово function объявляет функцию — именованный фрагмент кода, который можно вызвать. solve — выбранное имя. Параметр message — имя для значения, которое передаст вызывающий код. Инструкции между фигурными скобками составляют тело. Объявление само по себе не запускает тело: для этого нужен вызов solve('Привет').

```javascript
function echo(text) {
  return text;
}
console.log(echo('Учусь'));
console.log(echo('Пишу код'));
```

При первом вызове параметр text содержит строку 'Учусь', при втором — 'Пишу код'. Ключевое слово return передаёт значение обратно вызывающему коду и завершает вызов. Здесь используется один параметр и одна инструкция. Другие формы объявления, несколько параметров, область видимости и callbacks будут разобраны в главе о функциях; для этой задачи они не требуются.

## Возврат значения и вывод в консоль
Возвращённое значение и сообщение в консоли решают разные задачи. console.log помогает человеку увидеть сообщение, а return отдаёт значение программе. Проверяющая система вызывает solve и сравнивает возвращённый результат. Если написать только console.log(message), текст появится в журнале, но нужное значение не будет возвращено. Функция без return даёт специальное значение undefined, означающее здесь отсутствие результата.

```javascript
function show(text) {
  console.log(text);
}
console.log(show('Видимое сообщение'));
// Сначала появится сообщение, затем undefined.
```

В примерах можно сохранить значение через const: const result = echo('JS'). Это создаёт имя result для результата вызова. Кавычки вокруг 'JS' обозначают текст, а result без кавычек обращается к сохранённому значению. Подробно объявления переменных рассматриваются в следующем уроке. Сейчас достаточно различать готовый текст и имя параметра.

## Как замечать и исправлять ошибки
Движок должен разобрать структуру программы до выполнения. Пропущенная кавычка или закрывающая фигурная скобка приводит к SyntaxError: инструкции не удалось прочитать как корректный JavaScript. Начинайте с указанной строки и проверьте парность скобок и кавычек. Сравните программу с предоставленной оболочкой и найдите конкретное различие, вместо случайной замены символов.

```javascript
function echo(text) {
  return text;
}
console.log(echo('Скобки закрыты'));
```

Имена чувствительны к регистру: text и Text — разные имена. Если параметр называется text, обращение к Text не найдёт его и приведёт к ReferenceError. Текст после // до конца строки — комментарий, который движок не выполняет. Комментарий помогает читать программу, но не заменяет нужную инструкцию return.

## Практика без новых конструкций
В задаче solve(message) получает готовую строку и должна вернуть её без изменений. Не нужно определять среду выполнения, проверять условие, считать символы или спрашивать пользователя о вводе. Оболочка уже объявлена в редакторе. Внутри неё используйте имя параметра и return. Вызов solve('Привет') должен дать строку 'Привет', а не текст 'message'.

Проверьте непустое сообщение, другое слово и пустую строку ''. Пустой текст тоже является переданным значением: его нужно сохранить. Кнопка «Запустить примеры» показывает результаты опубликованных вызовов, а «Проверить решение» проверяет весь контракт. Перед запуском объясните, где параметр, где тело функции и куда попадёт возвращённая строка. Если эти шаги понятны, можно переходить к переменным.
